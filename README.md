# Student To-Do List

A simple, responsive student productivity web app built with HTML, CSS, and JavaScript.

## Features
- Add, edit, and delete tasks
- Mark tasks as completed
- Optional due dates and priority levels
- Filter all, pending, and completed tasks
- Task counters
- Saves tasks with browser Local Storage
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation or build tools are required.

## Publish with GitHub Pages
1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and the `/ (root)` folder, then click **Save**.
5. Wait a few minutes and open the Pages URL shown on that screen.

## Limitations
Tasks are saved only in the current browser on the current device. Clearing browser storage can remove them; this project does not include accounts or cloud synchronization.
